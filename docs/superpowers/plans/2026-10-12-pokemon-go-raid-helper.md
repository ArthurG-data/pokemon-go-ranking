# Pokémon GO Raid Helper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop web page that ranks Pokémon GO raid attackers per type and gym defenders, with French names, filters, search, and a "how to get it" panel, generated from public game data by a Python pipeline.

**Architecture:** `pipeline/` (Python, uv) downloads the PokeMiners Game Master, PokeAPI name CSVs and the ScrapedDuck LeekDuck feed, computes every form's movesets and ratings with the community comboDPS formulas, and writes one `web/data.json`. `web/` is a static page (plain HTML/CSS/JS, hash routing) that sorts and filters that file in the browser. No server, no bundler, no framework.

**Tech Stack:** Python 3.12, uv, pytest, pytest-playwright (one smoke test), vanilla HTML/CSS/JS. Zero runtime Python dependencies.

**Spec:** `docs/superpowers/specs/2026-10-12-pokemon-go-raid-helper-design.md`

## Global Constraints

- Python `>=3.12`, managed by uv; run everything as `uv run ...` from the repo root.
- Zero runtime dependencies in the pipeline (stdlib only). Dev deps: `pytest`, `pytest-playwright`.
- Ratings at **level 40, 15/15/15 IVs**: `CPM_40 = 0.7903`, `STAB = 1.2`, shadow attack `×1.2` / defense `×(1/1.2)`, reference target defense `180`, incoming pressure `900 / defense`, defender delay `+2000 ms` per move.
- Pokémon, form and move names shown in **French**; UI labels in English; search matches French and English.
- Each form is its own row: base, regional/stat forms, `_SHADOW`, `_MEGA`, `_MEGA_X`, `_MEGA_Y`, `_PRIMAL`.
- `web/data.json` is generated and **committed** (so the page works from GitHub Pages). `data/raw/` is git-ignored.

`pipeline/fetch.py`:
```python
"""Download and cache every upstream source into data/raw/."""
from __future__ import annotations

import sys
import time
from pathlib import Path
from urllib.request import urlopen

GM_URL = "https://raw.githubusercontent.com/PokeMiners/game_masters/master/latest/latest.json"
POKEAPI = "https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/"
DUCK = "https://raw.githubusercontent.com/bigfoott/ScrapedDuck/data/"

SOURCES: dict[str, str] = {
    "gamemaster.json": GM_URL,
    "pokemon_species.csv": POKEAPI + "pokemon_species.csv",
    "pokemon_species_names.csv": POKEAPI + "pokemon_species_names.csv",
    "pokemon.csv": POKEAPI + "pokemon.csv",
    "moves.csv": POKEAPI + "moves.csv",
    "move_names.csv": POKEAPI + "move_names.csv",
    "raids.json": DUCK + "raids.json",
    "eggs.json": DUCK + "eggs.json",
    "research.json": DUCK + "research.json",
}
RAW_DIR = Path("data/raw")


def _download(url: str) -> bytes:
    with urlopen(url, timeout=120) as resp:
        return resp.read()


def fetch_one(name: str, url: str, raw_dir: Path, *, force: bool = False, max_age_hours: float = 24.0,
              download=_download, now=time.time) -> Path:
    """Return the cached path for `name`, downloading when missing, stale or forced."""
    raw_dir.mkdir(parents=True, exist_ok=True)
    path = raw_dir / name
    if path.exists() and not force:
        age_hours = (now() - path.stat().st_mtime) / 3600
        if age_hours < max_age_hours:
            return path
    try:
        data = download(url)
    except Exception as exc:  # network / HTTP errors
        if path.exists():
            print(f"warning: could not refresh {name} ({exc}); keeping cached copy", file=sys.stderr)
            return path
        raise RuntimeError(f"could not download {name} from {url}: {exc}") from exc
    path.write_bytes(data)
    return path


def fetch_all(raw_dir: Path = RAW_DIR, *, force: bool = False, **kw) -> dict[str, Path]:
    return {name: fetch_one(name, url, raw_dir, force=force, **kw) for name, url in SOURCES.items()}


if __name__ == "__main__":
    for name, path in fetch_all(force="--force" in sys.argv).items():
        print(f"{name}: {path} ({path.stat().st_size // 1024} KB)")
```

```python
"""Extract small test fixtures from the real downloaded sources.

Run once after `uv run python -m pipeline.fetch`:  uv run python scripts/make_fixtures.py
"""
from __future__ import annotations

import csv
import json
from pathlib import Path

RAW = Path("data/raw")
OUT = Path("tests/fixtures")
SPECIES = [
    "CHARMANDER", "CHARMELEON", "CHARIZARD", "PICHU", "PIKACHU", "RAICHU", "DARUMAKA", "DARMANITAN",
    "MEWTWO", "DEOXYS", "HAPPINY", "CHANSEY", "BLISSEY", "DITTO", "LANDORUS", "GIRATINA", "KYOGRE",
    "KARTANA", "MEW", "ROTOM", "LUGIA",
]
MOVE_KEYS = ("quickMoves", "cinematicMoves", "eliteQuickMove", "eliteCinematicMove")


def subset_csv(name: str, keep) -> None:
    with open(RAW / name, newline="", encoding="utf-8") as f:
        rows = list(csv.DictReader(f))
    with open(OUT / name, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=list(rows[0].keys()))
        writer.writeheader()
        writer.writerows(r for r in rows if keep(r))


def main() -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    gm = json.loads((RAW / "gamemaster.json").read_text(encoding="utf-8"))
    keep, move_ids, dex = [], set(), set()
    for e in gm:
        data = e.get("data", {})
        if "typeEffective" in data:
            keep.append(e)
        elif "pokemonSettings" in data and data["pokemonSettings"]["pokemonId"] in SPECIES:
            keep.append(e)
            dex.add(int(e["templateId"][1:5]))
            for k in MOVE_KEYS:
                move_ids.update(data["pokemonSettings"].get(k, []))
    for e in gm:
        m = e.get("data", {}).get("moveSettings")
        if m and m["movementId"] in move_ids:
            keep.append(e)
    (OUT / "gm_small.json").write_text(json.dumps(keep), encoding="utf-8")

    idents = {m.removesuffix("_FAST").lower().replace("_", "-") for m in move_ids}
    subset_csv("pokemon_species.csv", lambda r: int(r["id"]) in dex)
    subset_csv("pokemon_species_names.csv",
               lambda r: int(r["pokemon_species_id"]) in dex and r["local_language_id"] in ("5", "9"))
    subset_csv("pokemon.csv", lambda r: int(r["species_id"]) in dex)
    with open(RAW / "moves.csv", newline="", encoding="utf-8") as f:
        pokeapi_move_ids = {r["id"] for r in csv.DictReader(f) if r["identifier"] in idents}
    subset_csv("moves.csv", lambda r: r["id"] in pokeapi_move_ids)
    subset_csv("move_names.csv", lambda r: r["move_id"] in pokeapi_move_ids and r["local_language_id"] in ("5", "9"))
    print("fixtures written:", sorted(p.name for p in OUT.iterdir()))


if __name__ == "__main__":
    main()
```

```python
"""Parse the PokeMiners Game Master into plain dataclasses, one row per usable form."""
from __future__ import annotations

import json
import re
from dataclasses import dataclass, field, replace
from pathlib import Path

TYPES = ["BUG", "DARK", "DRAGON", "ELECTRIC", "FAIRY", "FIGHTING", "FIRE", "FLYING", "GHOST", "GRASS",
         "GROUND", "ICE", "NORMAL", "POISON", "PSYCHIC", "ROCK", "STEEL", "WATER"]
_TYPE_PREFIX = "POKEMON_TYPE_"
_CLASS_PREFIX = "POKEMON_CLASS_"
_TEMP_PREFIX = "TEMP_EVOLUTION_"
# Costume / event clones that are not gameplay forms.
COSTUME_RE = re.compile(
    r"(COPY|COSTUME|FALL_|WINTER_|WCS|GOTOUR|TSHIRT|GOFEST|WILDAREA|HALLOWEEN|HOLIDAY|FASHION|PARTY"
    r"|ANNIV|FLYING_|KARIYUSHI|DOCTOR|LIBRE|POP_STAR|ROCK_STAR|VS_|^\d{4}$|_\d{4}$|_\d{4}_)"
)
MOVE_KEYS = ("quickMoves", "cinematicMoves", "eliteQuickMove", "eliteCinematicMove")


@dataclass(frozen=True)
class Move:
    id: str
    type: str
    power: float
    duration_ms: int
    energy: int

    @property
    def is_fast(self) -> bool:
        return self.id.endswith("_FAST")


@dataclass(frozen=True)
class Evolution:
    species: str
    candy: int


@dataclass
class Pokemon:
    id: str
    species: str
    dex: int
    form: str | None
    types: tuple[str, ...]
    base_atk: int
    base_def: int
    base_sta: int
    pokemon_class: str | None = None      # "LEGENDARY" | "MYTHIC" | "ULTRA_BEAST" | None
    is_shadow: bool = False
    mega: str | None = None               # "MEGA" | "MEGA_X" | "MEGA_Y" | "PRIMAL" | None
    fast_moves: tuple[str, ...] = ()
    charged_moves: tuple[str, ...] = ()
    elite_fast: tuple[str, ...] = ()
    elite_charged: tuple[str, ...] = ()
    parent: str | None = None
    buddy_km: float | None = None
    has_shadow: bool = False
    mega_ids: tuple[str, ...] = ()
    evolutions: tuple[Evolution, ...] = ()

    @property
    def legendary(self) -> bool:
        return self.pokemon_class in ("LEGENDARY", "ULTRA_BEAST")

    @property
    def mythical(self) -> bool:
        return self.pokemon_class == "MYTHIC"

    def all_fast(self) -> tuple[str, ...]:
        return self.fast_moves + tuple(m for m in self.elite_fast if m not in self.fast_moves)

    def all_charged(self) -> tuple[str, ...]:
        return self.charged_moves + tuple(m for m in self.elite_charged if m not in self.charged_moves)

    def is_elite(self, move_id: str) -> bool:
        return move_id in self.elite_fast or move_id in self.elite_charged


@dataclass
class GameMaster:
    pokemon: list[Pokemon]
    moves: dict[str, Move]
    type_chart: dict[str, dict[str, float]] = field(default_factory=dict)

    def by_id(self) -> dict[str, Pokemon]:
        return {p.id: p for p in self.pokemon}


def _strip_type(t: str) -> str:
    return t.removeprefix(_TYPE_PREFIX)


def _form_suffix(species: str, form: str | None) -> str | None:
    """'CHARIZARD_NORMAL' -> None, 'RAICHU_ALOLA' -> 'ALOLA', 'NIDORAN_NORMAL' -> None."""
    if not form:
        return None
    suffix = form.removeprefix(species + "_")
    if suffix == "NORMAL" or suffix.endswith("_NORMAL"):
        return None
    return suffix


def effectiveness(chart: dict[str, dict[str, float]], move_type: str, defender_types) -> float:
    mult = 1.0
    for t in defender_types:
        mult *= chart[move_type][t]
    return mult


def parse(entries: list[dict]) -> GameMaster:
    moves: dict[str, Move] = {}
    chart: dict[str, dict[str, float]] = {}
    raw_rows: list[tuple[int, dict]] = []
    for e in entries:
        data = e.get("data", {})
        tid = e.get("templateId", "")
        if "moveSettings" in data:
            m = data["moveSettings"]
            if m.get("durationMs") is None:
                continue
            moves[m["movementId"]] = Move(
                id=m["movementId"], type=_strip_type(m["pokemonType"]),
                power=float(m.get("power") or 0.0), duration_ms=int(m["durationMs"]),
                energy=int(m.get("energyDelta") or 0),
            )
        elif "typeEffective" in data:
            t = data["typeEffective"]
            chart[_strip_type(t["attackType"])] = dict(zip(TYPES, t["attackScalar"]))
        elif "pokemonSettings" in data and re.match(r"^V\d{4}_", tid):
            raw_rows.append((int(tid[1:5]), data["pokemonSettings"]))

    pokemon = _build_pokemon(raw_rows)
    missing = sorted({m for p in pokemon for m in p.all_fast() + p.all_charged() if m not in moves})
    if missing:
        raise ValueError(f"Pokémon reference moves missing from the Game Master: {', '.join(missing)}")
    return GameMaster(pokemon, moves, chart)


def _build_pokemon(raw_rows: list[tuple[int, dict]]) -> list[Pokemon]:
    groups: dict[tuple, list[tuple[int, str | None, dict]]] = {}
    for dex, p in raw_rows:
        species = p["pokemonId"]
        form = _form_suffix(species, p.get("form"))
        if form and COSTUME_RE.search(form):
            continue
        stats = p.get("stats") or {}
        if not stats.get("baseAttack"):
            continue
        types = tuple(_strip_type(t) for t in (p.get("type"), p.get("type2")) if t)
        key = (species, stats["baseAttack"], stats["baseDefense"], stats["baseStamina"], types,
               tuple(sorted(p.get("quickMoves", []))), tuple(sorted(p.get("cinematicMoves", []))))
        groups.setdefault(key, []).append((dex, form, p))

    out: list[Pokemon] = []
    seen: set[str] = set()
    for key, members in groups.items():
        members.sort(key=lambda m: (m[1] is not None, m[1] or ""))   # literal base row first
        dex, form, p = members[0]
        species, atk, dfn, sta, types = key[0], key[1], key[2], key[3], key[4]
        row_id = species if form is None else f"{species}_{form}"
        if row_id in seen:
            continue   # e.g. DEOXYS vs DEOXYS_NORMAL differ in detail; keep the base template
        seen.add(row_id)
        has_shadow = any("shadow" in m[2] for m in members)
        temp_evos: dict[str, dict] = {}
        for m in members:
            for t in m[2].get("tempEvoOverrides", []):
                if t.get("tempEvoId") and t.get("stats"):
                    temp_evos.setdefault(t["tempEvoId"].removeprefix(_TEMP_PREFIX), t)
        pokemon_class = (p.get("pokemonClass") or "").removeprefix(_CLASS_PREFIX) or None
        evolutions = tuple(Evolution(b["evolution"], int(b.get("candyCost", 0)))
                           for b in p.get("evolutionBranch", []) if b.get("evolution"))
        base = Pokemon(
            id=row_id, species=species, dex=dex, form=form, types=types,
            base_atk=atk, base_def=dfn, base_sta=sta, pokemon_class=pokemon_class,
            fast_moves=tuple(p.get("quickMoves", [])), charged_moves=tuple(p.get("cinematicMoves", [])),
            elite_fast=tuple(p.get("eliteQuickMove", [])), elite_charged=tuple(p.get("eliteCinematicMove", [])),
            parent=p.get("parentPokemonId"), buddy_km=p.get("kmBuddyDistance"),
            has_shadow=has_shadow, mega_ids=tuple(temp_evos), evolutions=evolutions,
        )
        out.append(base)
        if has_shadow:
            out.append(replace(base, id=f"{row_id}_SHADOW", is_shadow=True, has_shadow=False, mega_ids=()))
        for mega, t in temp_evos.items():
            mtypes = tuple(_strip_type(x) for x in (t.get("typeOverride1"), t.get("typeOverride2")) if x) or types
            s = t["stats"]
            out.append(replace(base, id=f"{row_id}_{mega}", types=mtypes, mega=mega,
                               base_atk=s["baseAttack"], base_def=s["baseDefense"], base_sta=s["baseStamina"],
                               has_shadow=False, mega_ids=(), evolutions=()))
    return out


def load(path: Path) -> GameMaster:
    return parse(json.loads(Path(path).read_text(encoding="utf-8")))
```

```python
"""Level-40 stats and the community comboDPS / TDO / rating formulas (GamePress style)."""
from __future__ import annotations

import math
from dataclasses import dataclass
from typing import NamedTuple

from .gamemaster import Move

CPM_40 = 0.7903
IV = 15
STAB = 1.2
SHADOW_ATK = 1.2
SHADOW_DEF = 1 / 1.2
TARGET_DEF = 180.0          # reference raid-boss defense the attacker hits
INCOMING = 900.0            # incoming damage pressure; y = INCOMING / defense
DEFENDER_DELAY_MS = 2000    # gym defenders pause 2 s between moves
DEFENDER_SCALE = 9.0        # sqrt(dps * hp * def) / scale ≈ 60 for the best defenders


@dataclass(frozen=True)
class Stats:
    atk: float
    dfn: float
    hp: int


class MoveScore(NamedTuple):
    dps: float
    eps: float


class ComboScore(NamedTuple):
    dps: float
    tdo: float
    rating: float


def level40_stats(base_atk: int, base_def: int, base_sta: int, *, shadow: bool = False) -> Stats:
    atk = (base_atk + IV) * CPM_40
    dfn = (base_def + IV) * CPM_40
    if shadow:
        atk *= SHADOW_ATK
        dfn *= SHADOW_DEF
    return Stats(atk, dfn, math.floor((base_sta + IV) * CPM_40))


def hit_damage(power: float, atk: float, target_def: float, multiplier: float) -> int:
    return math.floor(0.5 * power * atk / target_def * multiplier) + 1


def move_score(move: Move, stats: Stats, mover_types, eff: float = 1.0, *,
               target_def: float = TARGET_DEF, extra_ms: int = 0) -> MoveScore:
    mult = eff * (STAB if move.type in mover_types else 1.0)
    dmg = hit_damage(move.power, stats.atk, target_def, mult) if move.power > 0 else 0
    secs = (move.duration_ms + extra_ms) / 1000
    return MoveScore(dmg / secs, abs(move.energy) / secs)


def rating(dps: float, tdo: float) -> float:
    return (dps ** 3 * tdo) ** 0.25 if dps > 0 and tdo > 0 else 0.0


def combo(fast: Move, charged: Move, stats: Stats, mover_types, eff_fast: float = 1.0, eff_charged: float = 1.0,
          *, target_def: float = TARGET_DEF, extra_ms: int = 0) -> ComboScore:
    f = move_score(fast, stats, mover_types, eff_fast, target_def=target_def, extra_ms=extra_ms)
    c = move_score(charged, stats, mover_types, eff_charged, target_def=target_def, extra_ms=extra_ms)
    if charged.energy >= 0 or fast.energy <= 0 or f.eps + c.eps <= 0 or (f.dps == 0 and c.dps == 0):
        return ComboScore(0.0, 0.0, 0.0)
    y = INCOMING / stats.dfn
    x = -charged.energy * 0.5 + fast.energy * 0.5
    dps = (f.dps * c.eps + c.dps * f.eps) / (c.eps + f.eps) \
        + (c.dps - f.dps) / (c.eps + f.eps) * (0.5 - x / stats.hp) * y
    dps = max(dps, 0.0)
    tdo = dps * stats.hp / y
    return ComboScore(dps, tdo, rating(dps, tdo))


def defender_rating(def_dps: float, stats: Stats) -> float:
    return math.sqrt(max(def_dps, 0.0) * stats.hp * stats.dfn) / DEFENDER_SCALE
```

```python
def _read(path: Path) -> list[dict]:
    with open(path, newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))


def load_names(raw_dir: Path) -> Names:
    species_fr: dict[int, str] = {}
    species_en: dict[int, str] = {}
    for r in _read(raw_dir / "pokemon_species_names.csv"):
        table = {FR: species_fr, EN: species_en}.get(r["local_language_id"])
        if table is not None:
            table[int(r["pokemon_species_id"])] = r["name"]
    species_ident = {int(r["id"]): r["identifier"] for r in _read(raw_dir / "pokemon_species.csv")}
    move_ident = {r["id"]: r["identifier"] for r in _read(raw_dir / "moves.csv")}
    move_fr: dict[str, str] = {}
    move_en: dict[str, str] = {}
    for r in _read(raw_dir / "move_names.csv"):
        table = {FR: move_fr, EN: move_en}.get(r["local_language_id"])
        ident = move_ident.get(r["move_id"])
        if table is not None and ident:
            table[ident] = r["name"]
    pokemon_ids = {r["identifier"]: int(r["id"]) for r in _read(raw_dir / "pokemon.csv")}
    return Names(species_fr, species_en, species_ident, move_fr, move_en, pokemon_ids)


def split_form(form: str | None) -> tuple[str | None, str | None]:
    """'GALARIAN_STANDARD' -> ('GALARIAN', 'STANDARD'); 'ORIGIN' -> (None, 'ORIGIN')."""
    if not form:
        return None, None
    head, _, rest = form.partition("_")
    if head in REGIONS:
        return head, rest or None
    return None, form


def _title(s: str) -> str:
    return FORM_LABELS.get(s) or s.replace("_", " ").title()


def pokemon_name(p: Pokemon, names: Names, lang: str = "fr") -> str:
    table = names.species_fr if lang == "fr" else names.species_en
    name = table.get(p.dex) or _title(p.species)
    region, rest = split_form(p.form)
    xy = f" {p.mega[-1]}" if p.mega in ("MEGA_X", "MEGA_Y") else ""
    if lang == "fr":
        if region:
            name = f"{name} {REGIONS[region][0]}"
        if rest:
            name = f"{name} ({_title(rest)})"
        if p.mega:
            name = f"{MEGA_FR[p.mega]}{name}{xy}"
        if p.is_shadow:
            name = f"{name} Obscur"
    else:
        if region:
            name = f"{REGIONS[region][1]} {name}"
        if rest:
            name = f"{name} ({_title(rest)})"
        if p.mega:
            name = f"{MEGA_EN[p.mega]}{name}{xy}"
        if p.is_shadow:
            name = f"Shadow {name}"
    return name


def move_ident(move_id: str) -> str:
    return move_id.removesuffix("_FAST").lower().replace("_", "-")


def move_name(move: Move, names: Names, lang: str = "fr") -> str:
    table = names.move_fr if lang == "fr" else names.move_en
    return table.get(move_ident(move.id)) or move.id.removesuffix("_FAST").replace("_", " ").title()


def sprite_id(p: Pokemon, names: Names) -> int:
    ident = names.species_ident.get(p.dex)
    if ident is None:
        return p.dex
    parts: list[str] = []
    if p.mega:
        parts.append(MEGA_SPRITE[p.mega])
    else:
        region, rest = split_form(p.form)
        if region:
            parts.append(REGIONS[region][2])
        if rest:
            parts.append(rest.lower().replace("_", "-"))
    candidate = "-".join([ident, *parts])
    if candidate in names.pokemon_ids:
        return names.pokemon_ids[candidate]
    for name, pid in names.pokemon_ids.items():
        if name.startswith(candidate + "-"):
            return pid
    return names.pokemon_ids.get(ident, p.dex)
```

```python
"""'Right now' availability (raids, eggs, research) from the ScrapedDuck LeekDuck feed."""
from __future__ import annotations

import json
import re
from dataclasses import dataclass
from pathlib import Path

from .gamemaster import Pokemon
from .names import split_form

REGION_WORDS = {"Alolan": "ALOLA", "Galarian": "GALARIAN", "Hisuian": "HISUIAN", "Paldean": "PALDEA"}
_TAG_RE = re.compile(r"<[^>]+>")
_NOTE_RE = re.compile(r"^(.*?)\s*\((.*)\)\s*$")


@dataclass(frozen=True)
class FeedName:
    species: str
    shadow: bool = False
    mega: str | None = None
    region: str | None = None
    note: str | None = None


@dataclass(frozen=True)
class Now:
    kind: str    # "raid" | "egg" | "research"
    label: str   # tier, egg distance, or research task text
    who: str     # the feed's own name, for display and for the unmatched report


def parse_feed_name(name: str) -> FeedName:
    note = None
    m = _NOTE_RE.match(name.strip())
    if m:
        name, note = m.group(1), m.group(2)
    words = name.split()
    shadow, mega, region = False, None, None
    while words:
        w = words[0]
        if w == "Shadow":
            shadow = True
        elif w == "Mega":
            mega = "MEGA"
        elif w == "Primal":
            mega = "PRIMAL"
        elif w in REGION_WORDS:
            region = REGION_WORDS[w]
        else:
            break
        words.pop(0)
    if mega == "MEGA" and len(words) > 1 and words[-1] in ("X", "Y"):
        mega = "MEGA_" + words.pop()
    return FeedName(" ".join(words), shadow, mega, region, note)


def load_feed(raw_dir: Path) -> list[tuple[FeedName, Now]]:
    def read(name: str) -> list:
        return json.loads((raw_dir / name).read_text(encoding="utf-8"))

    out: list[tuple[FeedName, Now]] = []
    for r in read("raids.json"):
        out.append((parse_feed_name(r["name"]), Now("raid", r.get("tier", "Raid"), r["name"])))
    for r in read("eggs.json"):
        out.append((parse_feed_name(r["name"]), Now("egg", f"{r.get('eggType', '?')} eggs", r["name"])))
    for task in read("research.json"):
        label = _TAG_RE.sub("", task.get("text", "")).strip()
        for reward in task.get("rewards", []):
            if reward.get("name"):
                out.append((parse_feed_name(reward["name"]), Now("research", label, reward["name"])))
    return out


def _row_key(p: Pokemon, species_en: dict[int, str]) -> tuple:
    region, _ = split_form(p.form)
    return (species_en.get(p.dex, p.species).lower(), p.is_shadow, p.mega, region)


def match(pokemon: list[Pokemon], species_en: dict[int, str],
          feed: list[tuple[FeedName, Now]]) -> tuple[dict[str, list[Now]], list[str]]:
    index: dict[tuple, list[Pokemon]] = {}
    for p in pokemon:
        index.setdefault(_row_key(p, species_en), []).append(p)

    now_by_id: dict[str, list[Now]] = {}
    unmatched: list[str] = []
    for fname, now in feed:
        rows = index.get((fname.species.lower(), fname.shadow, fname.mega, fname.region), [])
        plain = [r for r in rows if split_form(r.form)[1] is None]
        if fname.note:
            tag = fname.note.upper().replace(" ", "_")
            rows = [r for r in rows if r.form and tag in r.form] or plain
        else:
            rows = plain or rows
        if not rows:
            unmatched.append(now.who)
            continue
        for r in rows:
            entries = now_by_id.setdefault(r.id, [])
            if now not in entries:
                entries.append(now)
    return now_by_id, unmatched
```

```python
"""Assemble web/data.json from the Game Master, the name tables and the availability feed."""
from __future__ import annotations

import argparse
import datetime as dt
import json
from pathlib import Path

from .availability import Now, load_feed, match
from .fetch import RAW_DIR, fetch_all
from .gamemaster import TYPES, GameMaster, Pokemon, load
from .names import ART_URL, SPRITE_URL, TYPE_NAMES_FR, Names, load_names, move_name, pokemon_name, sprite_id
from .scoring import DEFENDER_DELAY_MS, Stats, combo, defender_rating, level40_stats

OUT = Path("web/data.json")


def _movesets(p: Pokemon, gm: GameMaster, stats: Stats) -> list[dict]:
    out = []
    for f_id in p.all_fast():
        f = gm.moves[f_id]
        for c_id in p.all_charged():
            c = gm.moves[c_id]
            neutral = combo(f, c, stats, p.types)
            if neutral.rating <= 0:
                continue
            vs = {t: round(combo(f, c, stats, p.types, gm.type_chart[f.type][t], gm.type_chart[c.type][t]).rating, 1)
                  for t in TYPES}
            out.append({
                "fast": f_id, "charged": c_id, "type": c.type, "pure": f.type == c.type,
                "elite_tm": p.is_elite(f_id) or p.is_elite(c_id),
                "dps": round(neutral.dps, 1), "tdo": round(neutral.tdo), "rating": round(neutral.rating, 1),
                "vs": vs,
            })
    out.sort(key=lambda m: -m["rating"])
    return out


def _defender(p: Pokemon, gm: GameMaster, stats: Stats, *, allow_elite: bool) -> dict:
    best: tuple[float, str, str] | None = None
    for f_id in p.all_fast():
        for c_id in p.all_charged():
            if not allow_elite and (p.is_elite(f_id) or p.is_elite(c_id)):
                continue
            s = combo(gm.moves[f_id], gm.moves[c_id], stats, p.types, extra_ms=DEFENDER_DELAY_MS)
            if best is None or s.dps > best[0]:
                best = (s.dps, f_id, c_id)
    if best is None or best[0] <= 0:
        return {"rating": 0, "fast": None, "charged": None}
    return {"rating": round(defender_rating(best[0], stats), 1), "fast": best[1], "charged": best[2]}


def _sources(p: Pokemon) -> list[str]:
    if p.mega:
        return ["mega_energy"]
    if p.is_shadow:
        return ["rocket"]
    if p.mythical:
        return ["research"]
    if p.legendary:
        return ["raids"]
    return ["evolve"] if p.parent else ["wild", "eggs"]


def _evo_line(p: Pokemon, base_of: dict[str, Pokemon], names: Names) -> list[dict]:
    chain = [p.species]
    cur = base_of.get(p.species)
    while cur is not None and cur.parent and cur.parent not in chain:
        chain.insert(0, cur.parent)
        cur = base_of.get(cur.parent)
    line = []
    for i, species in enumerate(chain):
        row = p if i == len(chain) - 1 else base_of.get(species)
        if row is None:
            line.append({"id": species, "name_fr": species.title(), "sprite": None, "candy": None})
            continue
        candy = None
        if i < len(chain) - 1:
            candy = next((e.candy for e in row.evolutions if e.species == chain[i + 1]), None)
        line.append({"id": row.id, "name_fr": pokemon_name(row, names, "fr"),
                     "sprite": SPRITE_URL.format(sprite_id(row, names)), "candy": candy})
    return line


def build_data(gm: GameMaster, names: Names, now_by_id: dict[str, list[Now]], built: str | None = None) -> dict:
    species_rows: dict[str, list[Pokemon]] = {}
    for p in gm.pokemon:
        species_rows.setdefault(p.species, []).append(p)
    base_of: dict[str, Pokemon] = {}
    for p in gm.pokemon:
        if p.form is None and not p.is_shadow and p.mega is None:
            base_of.setdefault(p.species, p)
    for p in gm.pokemon:
        base_of.setdefault(p.species, p)

    rows = []
    for p in gm.pokemon:
        stats = level40_stats(p.base_atk, p.base_def, p.base_sta, shadow=p.is_shadow)
        sid = sprite_id(p, names)
        rows.append({
            "id": p.id, "species": p.species, "dex": p.dex, "form": p.form,
            "name_fr": pokemon_name(p, names, "fr"), "name_en": pokemon_name(p, names, "en"),
            "types": list(p.types),
            "flags": {"legendary": p.legendary, "mythical": p.mythical, "mega": p.mega is not None, "shadow": p.is_shadow},
            "stats": {"atk": p.base_atk, "def": p.base_def, "sta": p.base_sta},
            "l40": {"atk": round(stats.atk), "def": round(stats.dfn), "hp": stats.hp},
            "sprite": SPRITE_URL.format(sid), "art": ART_URL.format(sid),
            "forms": [q.id for q in species_rows[p.species] if q.id != p.id],
            "movesets": _movesets(p, gm, stats),
            "defender": _defender(p, gm, stats, allow_elite=True),
            "defender_no_elite": _defender(p, gm, stats, allow_elite=False),
            "get": {
                "evo_line": _evo_line(p, base_of, names),
                "buddy_km": p.buddy_km,
                "has_shadow": p.has_shadow or p.is_shadow,
                "megas": [f"{p.id}_{m}" for m in p.mega_ids],
                "sources": _sources(p),
                "now": [{"kind": n.kind, "label": n.label, "who": n.who} for n in now_by_id.get(p.id, [])],
            },
        })
    moves = {m.id: {"name_fr": move_name(m, names, "fr"), "name_en": move_name(m, names, "en"), "type": m.type,
                    "power": m.power, "dur": m.duration_ms, "energy": m.energy} for m in gm.moves.values()}
    return {
        "built": built or dt.date.today().isoformat(),
        "types": [{"id": t, "name_fr": TYPE_NAMES_FR[t], "name_en": t.title()} for t in TYPES],
        "pokemon": rows,
        "moves": moves,
    }


def build(raw_dir: Path = RAW_DIR, out: Path = OUT, *, fetch: bool = True, force: bool = False) -> dict:
    if fetch:
        fetch_all(raw_dir, force=force)
    gm = load(raw_dir / "gamemaster.json")
    names = load_names(raw_dir)
    now_by_id, unmatched = match(gm.pokemon, names.species_en, load_feed(raw_dir))
    data = build_data(gm, names, now_by_id)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps(data, ensure_ascii=False, separators=(",", ":")), encoding="utf-8")
    rankable = sum(1 for r in data["pokemon"] if r["movesets"])
    print(f"wrote {out}: {len(data['pokemon'])} rows ({rankable} rankable), {len(data['moves'])} moves, "
          f"{out.stat().st_size // 1024} KB")
    if unmatched:
        print("feed names not matched:", ", ".join(sorted(set(unmatched))))
    return data


def main(argv: list[str] | None = None) -> None:
    ap = argparse.ArgumentParser(description="Build web/data.json from the public Pokémon GO data sources.")
    ap.add_argument("--force", action="store_true", help="re-download every source even if cached")
    ap.add_argument("--no-fetch", action="store_true", help="use data/raw/ as is, never touch the network")
    args = ap.parse_args(argv)
    build(fetch=not args.no_fetch, force=args.force)


if __name__ == "__main__":
    main()
```

```js
'use strict';

const TYPE_COLORS = {BUG:'#a8b820',DARK:'#705848',DRAGON:'#7038f8',ELECTRIC:'#f8d030',FAIRY:'#ee99ac',FIGHTING:'#c03028',FIRE:'#f08030',FLYING:'#a890f0',GHOST:'#705898',GRASS:'#78c850',GROUND:'#e0c068',ICE:'#98d8d8',NORMAL:'#a8a878',POISON:'#a040a0',PSYCHIC:'#f85888',ROCK:'#b8a038',STEEL:'#b8b8d0',WATER:'#6890f0'};
const DARK_TEXT = new Set(['ELECTRIC', 'ICE', 'GROUND', 'STEEL', 'FAIRY']);
const STORAGE_KEY = 'goraid.settings';
const PLACEHOLDER = 'data:image/svg+xml;utf8,' + encodeURIComponent('<svg xmlns="http://www.w3.org/2000/svg" width="40" height="40"><circle cx="20" cy="20" r="14" fill="#ddd"/></svg>');

let DATA = null;
const BY_ID = new Map();
const state = {
  filters: {legendary: false, mythical: false, mega: false, shadow: false, elite: false},
  mode: 'attackers',
  topn: 25,
  sort: null,   // {key, dir}
};
const view = document.getElementById('view');

// ---------- settings persistence (per-viewer convenience; page works without it) ----------
function loadSettings() {
  try {
    const s = JSON.parse(localStorage.getItem(STORAGE_KEY) || 'null');
    if (s && s.filters) Object.assign(state.filters, s.filters);
    if (s && (s.mode === 'attackers' || s.mode === 'counters')) state.mode = s.mode;
    if (s && typeof s.topn === 'number') state.topn = s.topn;
  } catch (e) { /* private mode / blocked storage: defaults */ }
}
function saveSettings() {
  try { localStorage.setItem(STORAGE_KEY, JSON.stringify({filters: state.filters, mode: state.mode, topn: state.topn})); } catch (e) { /* ignore */ }
}

// ---------- helpers ----------
function esc(s) { return String(s).replace(/[&<>"']/g, c => ({'&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;'}[c])); }
function norm(s) { return String(s).normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase(); }
function typeName(t) { const x = DATA.types.find(y => y.id === t); return x ? x.name_fr : t; }
function chip(t, extra) { return `<span class="chip ${DARK_TEXT.has(t) ? 'dark-text' : ''} ${extra || ''}" style="background:${TYPE_COLORS[t]}">${esc(typeName(t))}</span>`; }
function moveName(id) { const m = DATA.moves[id]; return m ? m.name_fr : (id || '–'); }
function sprite(p, cls) {
  return `<img class="sprite ${cls || ''} ${p.flags.shadow ? 'is-shadow' : ''}" src="${p.flags.mega ? p.art : p.sprite}" alt="" loading="lazy" onerror="this.onerror=null;this.src='${PLACEHOLDER}'">`;
}
function badges(p) {
  let b = '';
  if (p.flags.mega) b += '<span class="tag mega">MEGA</span>';
  if (p.flags.shadow) b += '<span class="tag shadow">SHADOW</span>';
  if (p.flags.mythical) b += '<span class="tag leg">MYTH</span>';
  else if (p.flags.legendary) b += '<span class="tag leg">LEG</span>';
  return b;
}
function etm(ms) { return ms.elite_tm ? ' <span class="tag etm" title="Needs an Elite TM">ETM</span>' : ''; }
function bar(value, max, cls) {
  const w = max > 0 ? Math.round(value / max * 80) : 0;
  return `<span class="bar ${cls || ''}" style="width:${w}px"></span>${value.toFixed(1)}`;
}
function nameCell(p) { return `<a class="pname" href="#p/${encodeURIComponent(p.id)}">${sprite(p)}<span>${esc(p.name_fr)}</span>${badges(p)}</a>`; }

// ---------- ranking logic (all filtering happens here) ----------
function visible(p) {
  const f = state.filters;
  if (f.mega && p.flags.mega) return false;
  if (f.shadow && p.flags.shadow) return false;
  if (f.mythical && p.flags.mythical) return false;
  if (f.legendary && p.flags.legendary) return false;
  return true;
}
function legalMovesets(p) { return state.filters.elite ? p.movesets.filter(m => !m.elite_tm) : p.movesets; }
function defenderOf(p) { return state.filters.elite ? p.defender_no_elite : p.defender; }
function bestMoveset(p, typeId, mode) {
  let best = null, score = 0;
  for (const m of legalMovesets(p)) {
    if (mode === 'attackers' && m.type !== typeId) continue;
    const s = mode === 'attackers' ? m.rating : m.vs[typeId];
    if (s > score) { score = s; best = m; }
  }
  return best ? {ms: best, score} : null;
}
function rankedForType(typeId, mode) {
  mode = mode || state.mode;
  const rows = [];
  for (const p of DATA.pokemon) {
    if (!visible(p)) continue;
    const b = bestMoveset(p, typeId, mode);
    if (b) rows.push({p, ms: b.ms, score: b.score});
  }
  rows.sort((a, b) => b.score - a.score);
  return rows;
}
function rankedGym() {
  return DATA.pokemon.filter(p => visible(p) && defenderOf(p).rating > 0)
    .sort((a, b) => defenderOf(b).rating - defenderOf(a).rating);
}
function topSlice(rows) { return state.topn > 0 ? rows.slice(0, state.topn) : rows; }
function applySort(rows) {
  if (!state.sort) return rows;
  const {key, dir} = state.sort;
  const val = r => key === 'name' ? r.p.name_fr : key === 'dps' ? r.ms.dps : key === 'tdo' ? r.ms.tdo : key === 'defend' ? defenderOf(r.p).rating : r.score;
  return rows.slice().sort((a, b) => { const x = val(a), y = val(b); return (x < y ? -1 : x > y ? 1 : 0) * dir; });
}

// ---------- views ----------
function renderLanding() {
  const cards = DATA.types.map(t => {
    const top = rankedForType(t.id).slice(0, 3);
    const rows = top.map(r => `<a class="r" href="#p/${encodeURIComponent(r.p.id)}">${sprite(r.p)}<span>${esc(r.p.name_fr)}</span><b>${r.score.toFixed(0)}</b></a>`).join('');
    return `<div class="tcard" data-type="${t.id}">
      <a class="hd ${DARK_TEXT.has(t.id) ? 'dark-text' : ''}" style="background:${TYPE_COLORS[t.id]}" href="#type/${t.id}">${esc(t.name_fr)}</a>
      ${rows || '<div class="r muted">nothing with current filters</div>'}
      <a class="more" href="#type/${t.id}">see all →</a>
    </div>`;
  }).join('');
  view.innerHTML = `<h1 class="sr-only">Types</h1><div class="tgrid">${cards}</div>`;
}

function renderType(typeId) {
  if (!TYPE_COLORS[typeId]) { view.innerHTML = '<p>Unknown type.</p>'; return; }
  const all = rankedForType(typeId);
  const rows = topSlice(applySort(all));
  const max = all.length ? all[0].score : 0;
  const maxDef = Math.max(0, ...all.map(r => defenderOf(r.p).rating));
  const title = state.mode === 'attackers' ? `Best ${esc(typeName(typeId))} attackers` : `Best counters vs ${esc(typeName(typeId))}`;
  const th = (key, label) => `<th data-sort="${key}" class="${state.sort && state.sort.key === key ? (state.sort.dir > 0 ? 'asc' : 'desc') : ''}">${label}</th>`;
  const body = rows.map((r, i) => `<tr>
      <td>${i + 1}</td><td>${nameCell(r.p)}</td>
      <td>${esc(moveName(r.ms.fast))}</td>
      <td>${esc(moveName(r.ms.charged))}${etm(r.ms)}</td>
      <td>${r.ms.dps.toFixed(1)}</td><td>${Math.round(r.ms.tdo)}</td>
      <td>${bar(r.score, max, 'atk')}</td><td>${bar(defenderOf(r.p).rating, maxDef, 'def')}</td>
    </tr>`).join('');
```

```js
function bindSearch() {
  const input = document.getElementById('search');
  const list = document.getElementById('search-results');
  let results = [];
  const hide = () => { list.hidden = true; };
  const show = () => {
    const q = norm(input.value.trim());
    if (!q || !DATA) { hide(); return; }
    const score = p => {
      const fr = norm(p.name_fr), en = norm(p.name_en);
      if (fr.startsWith(q) || en.startsWith(q)) return 0;
      if (fr.includes(q) || en.includes(q)) return 1;
      return -1;
    };
    results = DATA.pokemon.map(p => ({p, s: score(p)})).filter(x => x.s >= 0)
      .sort((a, b) => a.s - b.s || a.p.dex - b.p.dex || a.p.id.localeCompare(b.p.id))
      .slice(0, 8).map(x => x.p);
    list.innerHTML = results.map(p => `<li><a href="#p/${encodeURIComponent(p.id)}">${sprite(p)}<span>${esc(p.name_fr)}</span><span class="muted">${esc(p.name_en)}</span>${badges(p)}</a></li>`).join('')
      || '<li class="muted">No match</li>';
    list.hidden = false;
  };
  input.addEventListener('input', show);
  input.addEventListener('focus', show);
  input.addEventListener('keydown', e => {
    if (e.key === 'Enter' && results.length) { location.hash = '#p/' + encodeURIComponent(results[0].id); input.blur(); hide(); }

  });
```

# Pokémon GO Raid Helper

Desktop web page that ranks Pokémon GO **raid attackers per type** and **gym defenders**, with French Pokémon
and move names, filters (legendary, mythical, mega, shadow, Elite TM moves), search, and a "how to get it"
panel with the evolution line and what is currently in raids, eggs and research.

Everything is computed from public data by a Python pipeline and written to one `web/data.json`;

## Usage

```bash

python3 -m http.server -d web 8000     # then open http://localhost:8000
```

## Data sources

| Source | Used for |
|---|---|
| [PokeMiners Game Master](https://github.com/PokeMiners/game_masters) | stats, moves, forms, type chart |
| [PokeAPI](https://github.com/PokeAPI/pokeapi) CSVs and sprites | French / English names, images |
| [ScrapedDuck](https://github.com/bigfoott/ScrapedDuck) (LeekDuck feed) | current raids, eggs, research |

## How ratings work

Level 40, 15/15/15 IVs. Attacker rating is GamePress-style `(DPS³ × TDO)^¼` from the comboDPS formula against a
reference boss (defense 180, neutral typing); the per-type "counters" score applies type effectiveness of each move.
The gym defender rating is a heuristic: `sqrt(defender DPS × HP × defense) / 9` with the defender's 2 s move delay.
Unreleased Pokémon in the Game Master are not filtered out.
